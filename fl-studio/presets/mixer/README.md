# Mixer track presets
Copy the `.fst` files to `<FL user data>\FL Studio\Presets\Mixer presets\`. They then appear in Browser → Mixer presets and in each mixer track's File menu.
- `MASTER - *.fst` (4: Hip Hop, RnB, Afrobeats, House): put on the Master track. [docs](../../../docs/master-presets.md)
- `VOX - *.fst` (24): put on vocal tracks. [docs](../../../docs/vocal-presets.md)
