Stem Mixer · Quick Guide

FL Studio 21 · stock plugins · one template for Hip Hop, R&B and Afrobeats

1 · Every project, 3 steps

  1. File → New, then drag all the pack's stems into the Playlist.
  2. Options → MIDI Settings → click loopMIDI Port → Controller type: Stem Mixer.
    Already set to Stem Mixer? Switch it to (generic controller) and back to Stem Mixer to run it again.
  3. Press F9. The mixer is built and every stem is already on the right track. View → Script output lists where each stem went.
Added more stems later? Repeat step 2. Your manual changes on track 24 and higher are never touched.

3 · One-time setup: plugins on the template (about 15 min)

Do this once in a fresh project, then save it (section 5). FL presets can't be made outside FL, so this is the one manual step.

TrackPlugins, in order
DRUMS BUSFruity Parametric EQ 2: low-cut 30 Hz → Fruity Compressor: ratio 2:1, attack 30 ms, release 150 ms, threshold until it turns down 1-3 dB
BASS BUSFruity Parametric EQ 2: low-cut 25 Hz → Fruity Limiter for the sidechain (box below)
MUSIC BUSFruity Parametric EQ 2: low-cut 120 Hz, gentle dip around 300 Hz if muddy
VOCAL BUSFruity Parametric EQ 2: low-cut 90 Hz → Fruity Compressor: 3:1, fast attack, 3-6 dB of turning down
REVERBFruity Reeverb 2: Dry 0%, Wet 100% → Fruity Parametric EQ 2: low-cut 250 Hz, high-cut 9 kHz → Fruity Limiter for the vocal duck (box below)
DELAYFruity Delay 3: Dry 0%, time 1/4 beat, low feedback → Fruity Parametric EQ 2: low-cut 300 Hz, high-cut 7 kHz
Sending a track to REVERB or DELAY: select the track (e.g. LEAD VOCAL) → left-click the small arrow under REVERB → turn the little send knob on that arrow down to about -10 dB, then raise to taste. Good candidates: lead vocal, backing, snare, chords, melodies.
The only 2 sidechain links you need (select the trigger track → right-click the small arrow under the target track → Sidechain to this track):
  1. KICK → BASS BUS. In that Fruity Limiter, turn CEIL up, switch to COMP, right-click SIDECHAIN → KICK, ratio 4:1, lower the threshold until the bass dips on each kick. No kick stem? Use DRUMS LOW.
  2. LEAD VOCAL → REVERB. Same Limiter steps (trigger: LEAD VOCAL). The reverb dips while the vocal sings, so words stay clear.

Tweak by ear: more FEEDBACK = more repeats, lower CUTOFF = darker. To save your tweak: plugin menu (top-left arrow) → Save preset as…. Manual maths if ever needed: 1/4 note in ms = 60,000 ÷ BPM (86 BPM = 698 ms).

Balancing order (all genres)

  1. Pull the 4 bus faders until each peaks around -6 dB and the Master peaks around -6 to -3 dB before mastering.
  2. Kick + bass first → rest of drums → lead vocal 3-6 dB above the loudest instrument → music → FX.
  3. Bass tracks: turn the track's stereo separation knob fully to merged (mono).

5 · Mastering presets (already installed on your PC)

Load one in 2 clicks: in the Mixer, right-click the Master track name → File → pick MASTER - Afrobeats, MASTER - Hip Hop or MASTER - RnB. Then raise the Fruity Limiter GAIN until you reach the loudness target.
#Plugin (Master slots 1-4)MASTER - Hip HopMASTER - RnBMASTER - Afrobeats
1Fruity Parametric EQ 2FL preset "20Hz + 18kHz cut": removes rumble and harsh ultra-highs

The compressor's "threshold" decides how hard it works. Play the loudest part and aim for 1-2 dB of turning down. If it's more, raise THRESHOLD a little. Tweaked a preset you like? Right-click Master → File → Save mixer track state as… to save your own version. Backup copies of the 3 presets are in the ZIP (Mixer presets folder).

Measuring loudness: FL 21 has no simple loudness (LUFS) meter built in. Add the free Youlean Loudness Meter as the very last plugin on the Master. It only measures. Keep True Peak ≤ -1 dB.

Final checks

  • Unmute track 17 (FULL MIX REF) and compare. Are your low end and vocal as clear?
  • Listen on phone speakers and earphones. Is the 808 / log drum still audible?
  • Switch the whole Master chain off and on. It should sound better, not just louder.

6 · Optional: save the bus plugins as a template

The script rebuilds the mixer every time, so you don't need a template. To skip redoing section 3 each time: after adding those plugins in an empty project (no stems), File → Save as… → Stem Mixer Template.flp. Open it, drag stems in, then run Stem Mixer. It keeps your plugins and just routes the stems.

If something's off: View → Script output shows what the script did. A stem on the wrong track? In the Channel Rack, change its mixer track number by hand. If the script ran on a project with its own named mixer tracks, it skips it on purpose (use File → New).
